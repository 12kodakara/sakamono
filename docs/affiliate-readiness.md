# アフィリエイトを入れるときの手順と、追記が必要なこと

ASP（Webgains など）と提携したときに、何を直せばよいかをまとめたものです。

**まだ提携していません。** 広告リンク・計測タグ・Cookie 同意バナーは1つも入っていません。
このファイルは、入れるときに迷わないための準備です。

## 1. 用意してある仕組み（コードの変更はほぼ不要）

### 広告であることの表示

`src/components/layout/SponsoredNote.tsx` が、押すボタンの直前に出ます。

**広告リンクがあるページにだけ出ます。** 出すかどうかは
`buildPurchaseLink()` が返す `isSponsored` で決まり、その値は
**掲載ストアの `affiliateAvailable`** から来ます。
提携していないあいだは描画されません（いまはどのページにも出ていません）。

### `rel="sponsored"`

`src/lib/purchaseLink.ts` の `relFor()` が決めます。

- 広告リンク … `noopener sponsored`
- それ以外 … `noopener nofollow`

### 切り替え方

**コードを直すのではなく、データを直します。**

1. 提携したストアの `affiliateAvailable` を `true` にする（`src/data/fixtures/stores.ts`）
2. そのストアの掲載URL（`externalUrl`）を、ASPが指定する計測用URLにする
3. 以上で、広告の表示と `rel="sponsored"` が同時に付きます

> ★ASPの仕様を推測して先に作り込んでいません。★
> 計測用URLの形・パラメータ・必須の固定文言は、提携が決まってから
> ASPの資料で確認し、そのとおりにデータへ入れてください。

## 2. プライバシーポリシーへ追記すること

`src/app/privacy/page.tsx` を更新します。**最終更新日（`LAST_UPDATED`）も必ず直してください。**

現在のポリシーには、次の3か所に「いまは無い」と書いてあります。
提携したら、この3か所が事実と違うことになります。

| 現在の記載 | 提携後にすること |
| --- | --- |
| 「広告・アフィリエイトのリンクはありません」 | 掲載していることと、下記の内容へ書き換える |
| 「Cookie などを使用していません」 | ASPがCookieを使う場合は、その事実と目的を書く |
| 「外部のスクリプトを読み込みません」 | 計測タグを入れる場合は、その事実を書く |

追記する内容（ASPの資料で確認してから書く）:

- **事業者名** … 提携するASPの正式名称
- **何のために** … 成果（購入など）の計測のため
- **何が送られるか** … ASPが取得する情報（Cookie、クリック情報、参照元など。ASPの説明に従う）
- **保存期間** … ASPが定める期間
- **オプトアウトの方法** … ASPが案内している方法へのリンク
- **第三者への提供** … ASPへ渡る情報があること

## 3. 景品表示法・ステルスマーケティング規制について

2023年10月から、広告であることを隠した表示は景品表示法上の不当表示として
規制の対象になっています。

このサイトで必要なのは次の2つです。

1. **広告だと分かる表示を、見落とされない場所に置く**
   → `SponsoredNote` をボタンの直前に置いてあります
2. **掲載内容が紹介料の有無で変わらないこと**
   → 表示文にその旨を書いてあります。並び順や推薦の基準を
     紹介料で変えないでください（変えるなら、その旨の表示が必要になります）

**使ってはいけない表現**（実データで裏づけられないため）:
「最安値」「今だけ」「○%OFF」のような断定。
価格の表示そのものについては `src/lib/priceDisclosure.ts` を参照してください。

- [ ] `rel="sponsored"` が付いたことを確認した
- [ ] プライバシーポリシーを更新し、最終更新日も直した
- [ ] ASPが求める固定文言があれば、指定どおりに掲載した
- [ ] Cookie 同意の取得が必要かを、ASPの仕様に照らして判断した
- [ ] テスト・型チェック・ビルドを通した

## 5. 判断していないこと

**法的な適法性は判断していません。** ここに書いたのは実装の仕組みと、
確認が必要な項目の整理です。表示義務の有無や文面の十分さについては、
必要に応じて専門家に確認してください。

特定商取引法については、サカモノが自ら商品を販売していないため
通信販売事業者としての表示義務は生じないと考えられますが、断定はしていません。
