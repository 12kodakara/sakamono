## 3. robots.txt の確認 ✅ 確認済み

`https://store.liverpoolfc.com/robots.txt`（2026-09-19 取得）

### 禁止されているパス

```
User-agent: *

# トラッキング／キャンペーンパラメータ
Disallow: /*?*gclid=*   /*?*queryID=*   /*?*utm_campaign=*
Disallow: /*?*utm_medium=*   /*?*utm_proposition=*   /*?*utm_source=*

# Algolia の絞り込みファセット
Disallow: /*?*f_*

# 並び替え・価格帯
Disallow: /*?*sort=*   /*?*min_price=*   /*?*max_price=*

# 検索
Disallow: /search   /*/search   /*?*q=*

# 旧 Magento パス
Disallow: /media/catalog/product/cache/   /admin/   /sales/order/   /catalogsearch/

# WordPress の探索
Disallow: /wp-content/   /wp-admin/   /wp-includes/   /wp-login.php
```

### 読み取れること

- **商品詳細ページ・カテゴリページ自体は Disallow されていない**
- `Crawl-delay` の指定は**無い**
- 14ロケール分の sitemap が公開されている（`/jp/sitemap.xml` を含む）

### ⚠️ 重要な注意

**robots.txt が許可していることと、利用規約が許可していることは別です。**
robots.txt は「クローラに読み込ませてよいか」を示すだけで、
「読み込んだ内容を自分のデータベースへ入れて再配信してよいか」は示しません。
次章の利用規約が実際の制約になります。

## 4. 利用規約の確認 ✅ 確認済み（これが今回の決定要因）

- 英語版: `https://store.liverpoolfc.com/customer-services/terms-conditions`
- 日本向け: `https://store.liverpoolfc.com/jp/customer-services/terms-conditions`
  （**同一の条文**。本文は英語、ナビゲーションのみ日本語）

### 第15.7条（Intellectual property）原文

> "All content which features on our website ... is protected by copyright, trade mark rights
> and/or other intellectual property rights owned by or licensed to us"
>
> **"You must not, nor try to, make mass, automated or systematic extractions of the LFC Content,
> or use it to create or include it within another paper or electronic database,
> or try to re-sell or re-distribute it."**

### サカモノがやろうとしていたことと照らすと

| 規約が禁止していること | サカモノの第3段階の計画 | 判定 |
| --- | --- | --- |
| mass / automated / systematic extraction | 商品一覧を自動で巡回して取得する | ❌ 該当 |
| 別の電子データベースへ取り込む | `Product` / `StoreListing` として保存する | ❌ 該当 |
| 再配信する | 価格比較サイトとして公開表示する | ❌ 該当 |

**3項目すべてに正面から該当します。** 件数を10件に絞っても、
自動・体系的な抽出をデータベース化して再配信する点は変わりません。

> 補足: 商品名・価格そのものが著作物にあたるかは法域により議論があります。
> しかし規約は「契約」として別に効力を持ちます。
> サカモノは日本から英国企業のサイトへアクセスするため、
> 準拠法・裁判管轄の確認も必要です（⬜ 未確認）。
> いずれにせよ、**規約が明示的に禁じている行為を承知のうえで続けるべきではありません。**

### この方式が優れている理由

1. **規約上クリア** — 権利者自身が publisher へ提供しているデータです
2. **壊れにくい** — 構造化フィード。HTMLの作り替えで壊れません
3. **サイトへ負荷をかけない** — フィードのダウンロードは1回
4. **第4段階以降の収益化と地続き** — サカモノは元々アフィリエイトを想定しています
5. **ディープリンクが許可されている** — 「商品を見る」リンクを正規の形で出せます

## 8. 送料について

| 項目 | 内容 |
| --- | --- |
| 日本向け送料 | ⬜ **未確認** |
| 取得方法 | 商品ページからは確定できない見込み（🟡 推測） |
| サカモノでの扱い | **`ShippingRule.type = 'unknown'`** |

第2段階で作った「不明を0円にしない」仕組みをそのまま使います。
根拠のない固定送料を置くことはしません。

結果として、Liverpool 実データを表示すると
**「国際送料を除く参考額」**として表示され、日本到着推定額は算出されません。
これは仕様どおりの正しい挙動です。

送料の根拠が得られた時点で、`shippingRules` に `fixed` / `threshold` / `estimated` を追加すれば
表示は自動的に「日本到着推定額」へ切り替わります。

1. **CAPTCHA・bot protection の回避は行っていません。** 存在の確認すら試していません。

## 11. 最終判定

### 🔴 STOP — HTML / 内部APIからの自動取得は実行しない

**理由**: 利用規約 第15.7条が、
「mass, automated or systematic extractions」「別の電子データベースへの取り込み」「再配信」
の3つを明示的に禁止しており、サカモノの用途はその3つすべてに該当するため。

robots.txt が商品ページを許可していることは、この判断を覆しません。

### 🟡 条件付きGO — Webgains 公式商品フィード経由

**条件**:
1. Webgains のプログラム7413へ申請し、承認を得る
2. フィードの実項目（SKU / EAN / サイズ / 在庫 / regularPrice）を確認する
3. 価格比較サイトでの利用が認められることを確認する
4. 画像URLの利用条件を確認する

この4点が満たされれば、サカモノ側の受け入れ準備（本段階で構築済み）へ
そのまま流し込めます。

## 12. サカモノ側の準備状況（第3段階で実装したもの）

**取得経路が決まっていなくても作れる部分は、すべて作ってあります。**

```
生データ（どの経路から来ても同じ形へ）
  LiverpoolRawProduct / LiverpoolRawVariant
      ↓  検証（外部データを信用しない）
  validateLiverpoolRawProduct
      ↓  正規化
  LiverpoolAdapter
      ↓
  Product / StoreListing / ProductVariant / PriceSnapshot
      ↓
  LiverpoolDataSource（SakamonoDataSource 実装）
      ↓
  既存の価格計算エンジン（第2段階）— 変更不要
```

- 取得元は `LiverpoolRawSource` インターフェースで差し替え可能
- 現在の実装は**ローカルファイルから読む `FileRawSource` のみ**
- **HTTPで取りに行くコードは意図的に実装していません**（規約上の判断のため）
- フィード入手後は、フィードを `LiverpoolRawProduct[]` へ写す変換を1つ足すだけで動きます

詳しくは [README](../../README.md) の「第3段階」の章を参照してください。
