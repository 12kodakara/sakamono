| 外部APIのサンプル応答（`src/data/external` の各 sample ファイル） | — | CLIとテスト専用。本番の商品データではない |

### なぜ掲載・価格を今回消さなかったか

消した場合を計算した結果（削除はせず試算のみ）:

| | 現状 | example.com 掲載を全削除した場合 |
| --- | --- | --- |
| 価格のある商品 | 10 | **0** |
| index / sitemap | 23 | **11** |
| セール一覧 | 5件 | 0件（ページは noindex になる） |
| 価格差ランキング | 7件 | 0件（同上） |

サイトは全ページで「開発中のサンプル表示です。表示している価格・在庫・割引率はすべて動作確認用のサンプル値で、
実際の販売情報ではありません」と明示しています。掲載と価格は、この**開発用データセットそのもの**です。

いま一括削除すると、価格比較サイトとしての表示と、価格比較の回帰テスト群（ケースA〜F など）が同時に失われます。
これは「ダミーの除去」ではなく設計変更にあたるため、次の順番で進めます。

1. 実データの置き場所（本番用）を、開発用データセットと分ける
2. クラブ・種類ごとに、実際の掲載・価格を入れて置き換える
3. 置き換えが済んだ商品から、対応する開発用の掲載を外す

| 一部のみ確認 | 2 | 2 |
| 確認できていない | 8 | **3** |

5商品を公式一次情報で確認済みへ引き上げました（記録は `manual-official-checks.md`）。
残る3件は、いずれも最初のコミット `222ea35` で手書きされたもので、
リポジトリにも履歴にも外部への手掛かりが1つも残っていません。

- `product-lfc-2526-training-top` … 初回の品番が `SAMPLE-LFC-2526-TR`。**実在商品を指していなかったことが確定**
- `product-thfc-2526-scarf` … 元URL・品番・色・画像なし。公式ストアに複数のマフラーが存在し特定不能
- `product-lfc-2526-anthem-jacket` … 該当する公式商品の存在までは確認できたが、結び付ける一次証拠がない

**追加調査を続けても改善が見込めないため、Grade を0にすること自体は目的にしません。**

### 5.2 トレーニングトップを公開導線から外しました

3件のうち、これだけが**誤った事実を公開していました**。

| | 変更前 | 変更後 |
| --- | --- | --- |
| メーカー | `Nike`（2025/26のリヴァプールは adidas。**誤り**） | `確認中` |
| robots | `index, follow` | **`noindex, follow`** |
| sitemap | 掲載 | 外れた（23→22） |
| セール一覧 | 掲載（5件中） | 外れた（4件） |
| トップページ | 掲載 | 外れた |
| 商品ページ | 生成・到達可能 | **変更なし**（URL・canonical も同じ） |

やったことは2つだけです。

1. **メーカーを `確認中` にした。** `adidas` へ書き換えると、どの商品か分かっていないレコードの
   見かけの信頼性だけが上がってしまいます。確認できていないことを、そのまま示します。
   （`確認中` は取り込み処理・照合エンジンが既に使っている印です）
2. **サンプル掲載 `listing-lfc-training-official` を外した。** 価格が無くなると、
   `isProductListable`（`src/lib/sitemap.ts`）の既存ルールだけで noindex・sitemap除外・
   セール除外・トップ除外が同時に成立します。**SEOの新ルールは追加していません。**

商品そのものは残してあります。実在商品へ置き換えるときに使います。
「国内の比較対象が見つかっていない商品」の表示確認は、トッテナム 2025/26 アウェイが引き継ぎました。

### 5.3 同じ誤りを二度と入れないための検査

商品IDを並べる方式（`KNOWN_WRONG`）をやめ、**表による再利用可能なルール**へ置き換えました
（`src/tests/officialChecks.test.ts`）。

- クラブ×シーズンの公式サプライヤー表を1つ持つ
- **品番が確認済みの商品**は、その表のメーカーと一致すること（2024/25=Nike と 2025/26=adidas を同時に固定）
- **品番が未確認の商品**は、根拠のないブランド名を名乗らないこと
  （名乗ってよいのは「そのシーズンのサプライヤー」「クラブ自身の名前」「確認中」だけ）
- **メーカーが `確認中` の商品は価格を持たない**＝検索結果へ出ない

トレーニングトップの `Nike` を元に戻すと、3つ目の検査が
`product-lfc-2526-training-top: Nike` を指摘して落ちることを確認済みです。
クラブやシーズンが増えても、表へ1行足すだけで検査対象に入ります。
