# 人手による公式情報の確認記録

**方式名**: ユーザー提供の人手確認済み一次情報（USER_MANUAL_OFFICIAL）
**目的**: 自動取得できない公式情報（ボット対策・規約上の理由で取得しない公式サイト）を、
人が通常のブラウザで確認し、その結果を商品データの根拠として記録する。

---

## 0. この方式のきまり

| 項目 | きまり |
| --- | --- |
| 確認する人 | サカモノの運営者（通常のブラウザで閲覧） |
| 確認できる情報源 | クラブ公式・メーカー公式のドメインに属する情報だけ |
| 記録するもの | 確認者が画面で見た値だけ。**画面に無い値は書かない（推測で補わない）** |
| 主な識別子 | **メーカー品番（製品コード）**。完全一致したときだけ「同一商品」とする |
| 価格・在庫 | **変動情報**。「確認時点の参考値」として記録するだけ。**商品データへ保存しない**（下の表の値は受領日時点のもので、現在の値ではない） |
| 商品URL | 検索結果ページのURLは保存しない。商品詳細URLを安全に特定できない場合は未設定のまま |
| 画像 | 公式画像を転載しない。画像URLも登録しない |
| 自動取得との関係 | サカモノのプログラムは、この確認のために公式サイトへアクセスしない |

### 根拠の強さ

この方式の根拠は、**公式ドメイン（adidas.jp）の検索結果表示を人が確認したもの**です。
公式ページ本体を人が開いて確認した場合より一段弱い根拠として扱い、
商品詳細ページを確認できたときは、この記録を更新してください。

## 2. サカモノのデータへの反映

- **1-1〜1-4（JV6487・JV6456・JV6436・JV6423）：** 値は変更していません。既存の値（品番・クラブ・シーズン・種類・仕様・メーカー・袖・対象）が、すでに公式表示と一致していたためです。
- **1-5・1-6（KA6855・JY4237）：** 未設定だった品番だけを追加しました。ほかの値は公式表示と一致していたので変更していません。
- **カラー・素材・エンブレムの記載は、データへ入れていません。** 今のデータモデルに項目が無いためです（この記録にだけ残します）。
- **選手名入り（product-lfc-2526-home-replica-salah）は、無地と同じ品番 JV6423 を持ったままです。** マーキングは後から入れるため実際に同じ品番になるという、照合エンジンの回帰テスト用の設計です。この商品は公式確認できていないので、Grade B のままです。
- **商品名（nameJa）は変えていません。** サイト内の全商品で「クラブ名 シーズン 種類 仕様 ユニフォーム（違い）」の形にそろえているためです。公式商品名は、この記録に残します。将来、公式商品名を持つ項目を作るときに移します。
- 価格・在庫・商品URL・画像は登録していません。
