# 人手による公式情報の確認記録

**方式名**: ユーザー提供の人手確認済み一次情報（USER_MANUAL_OFFICIAL）
**目的**: 自動取得できない公式情報（ボット対策・規約上の理由で取得しない公式サイト）を、
人が通常のブラウザで確認し、その結果を商品データの根拠として記録する。

---

## 0. この方式のきまり

| 項目 | きまり |
| --- | --- |
| 確認する人 | サカモノの運営者（通常のブラウザで閲覧） |
| 確認できる情報源 | クラブ公式・メーカー公式のドメインに属する情報だけ |
| 記録するもの | 確認者が画面で見た値だけ。**画面に無い値は書かない（推測で補わない）** |
| 主な識別子 | **メーカー品番（製品コード）**。完全一致したときだけ「同一商品」とする |
| 価格・在庫 | **変動情報**。「確認時点の参考値」として記録するだけ。**商品データへ保存しない**（下の表の値は受領日時点のもので、現在の値ではない） |
| 商品URL | 検索結果ページのURLは保存しない。商品詳細URLを安全に特定できない場合は未設定のまま |
| 画像 | 公式画像を転載しない。画像URLも登録しない |
| 自動取得との関係 | サカモノのプログラムは、この確認のために公式サイトへアクセスしない |

### 根拠の強さ

根拠には2段階あります。記録ごとに「確認方法」の行で区別しています。

| 強さ | 確認方法 | 該当 |
| --- | --- | --- |
| 強 | 公式の個別商品ページを人が開いて確認 | 1-4 / 1-5 / 1-6 / 1-7 / 1-8 |
| 中 | 公式ドメインの検索結果表示を人が確認 | 1-1 / 1-2 / 1-3 |

「中」の記録は、商品詳細ページを確認できたときに更新してください。
